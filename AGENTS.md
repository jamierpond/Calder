# Agents working on Calder

This repository is public. Never add anything about Tamber's internals:
product code, private repo names other than emberstore, machine names, paths
on Jamie's machines, secrets, or customer data. Check every change for these
before committing.

The spec is the source of truth. Any change to the format updates `SPEC.md`
and the Python decoder in the same commit, and the decoder is written from the
spec, not from the C++ encoder.
